# Hackthon — Option 2

An alternate concept for Hackthon, inspired by the product storytelling and crisp interface of the supplied Dovetail reference. The visual language is its own: a midnight workspace, bright signal-green focus, and synthetic challenge intelligence written for a maker event.

## Prototype features

- Responsive event hero with a live countdown and interactive Signal Desk
- Four selectable challenge tracks
- Interactive event journey
- Three synthetic featured projects
- Rotating team-match preview
- Accessible local registration-interest dialog with validation
- Mobile navigation, keyboard support, and reduced-motion behavior

This is a visual and interaction sample, not the final feature set. Project, team, event, and Signal Desk content are examples. Form entries stay on screen, are not transmitted, and are not persisted.

## Run locally

```bash
npm install
npm run dev
```

## Verify

```bash
npm test
npm run build
```

## Deployment

This site is built and deployed alongside Option 1 by the repository's GitHub Pages workflow. It is published at `/hackthon/option-2/`.
